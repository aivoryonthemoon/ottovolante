# Ottovolante

Sito di Mauro Ottolini e dell'Orchestra Ottovolante.

**Sito pubblico:** https://mooooonn.github.io/ottovolante/

## Anteprima locale

Con Node.js installato:

```sh
npm run dev
```

Aprire http://localhost:5188/.

## Pubblicazione

Il sito statico è nella cartella `public/`. Ogni aggiornamento al branch `main`
pubblica automaticamente questa cartella su GitHub Pages tramite il workflow
`.github/workflows/pages.yml`. Non è necessaria una compilazione.

Foto, font e download sono inclusi. I video YouTube richiedono una connessione
a Internet e vengono caricati quando si preme il pulsante di riproduzione.
